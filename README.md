# JI Fahad Portfolio Website

## Open locally
1. Extract the ZIP.
2. Double-click `index.html`.
3. The site will open in your browser.

## Edit
- Main content: `index.html`
- Design/colors/layout: `style.css`
- Navigation/mobile behavior: `script.js`

## Important placeholders
Replace these in `index.html`:
- `your.email@example.com`
- LinkedIn / Google Scholar / GitHub `href="#"` links
- Publication DOI/journal links
- Any project descriptions or dates you want to update.

The Google Fonts are loaded from the internet. The website itself works locally without a server, but the font will fall back to system fonts if offline.
